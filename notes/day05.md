# Day5 EC11 页面交互优化与消抖

## 1. 今日目标

在 Day4 EC11 左旋、右旋、按下基础识别的基础上，优化旋钮交互逻辑，让 OLED 页面切换更加稳定。

Day5 的重点不是新增硬件，而是把旋钮从“能识别”优化成“能稳定使用”。

## 2. 今日完成内容

- 优化 EC11 旋钮事件识别
- 增加旋转消抖
- 增加按键消抖
- 右旋控制 OLED 切换到下一页
- 左旋控制 OLED 切换到上一页
- 按下控制进入或退出设置页
- 删除主循环中的长时间阻塞延时
- 取消 OLED 无条件高频刷新
- 使用 `HAL_GetTick()` 维护 DHT11 采集周期和 OLED 刷新周期

## 3. 当前硬件连接

| EC11 模块 | STM32F103C8T6 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| C | GND |
| A | EC11_A |
| B | EC11_B |
| SW | EC11_SW |

说明：

- A/B 是旋转编码信号
- SW 是按键输入信号
- C 是旋钮公共端，需要接 GND
- A/B/SW 均配置为 GPIO 输入上拉

## 4. 今日核心思想

今天的核心链路是：

```text
EC11 旋转或按下
    ↓
EC11_Update() 扫描 A/B/SW 电平
    ↓
产生 EC11_Event 事件
    ↓
EC11_GetEvent() 取出并清除事件
    ↓
main.c 根据事件修改 current_page
    ↓
OLED_UI_ShowPage() 刷新当前页面
