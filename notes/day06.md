# Day6 LED 舒适度指示

## 1. 今日目标

在 Day5 EC11 页面交互优化的基础上，接入 LED 舒适度指示功能。

目标是让系统不仅能在 OLED 上显示温湿度和舒适度，还能通过 LED 直观反馈当前环境状态。

## 2. 今日完成内容

- 新增 `led_status.h`
- 新增 `led_status.c`
- 配置 PB12 / PB13 / PB14 为 GPIO 输出
- 使用 3 个 LED 表示不同舒适度
- 将 `ComfortLevel` 枚举与 LED 状态绑定
- 在 DHT11 采集成功后更新 LED 状态
- 保持 OLED 显示和 EC11 页面切换正常运行

## 3. 硬件连接

| 功能 | STM32F103C8T6 | LED |
|---|---|---|
| 舒适 | PB12 | 绿灯 |
| 一般 | PB13 | 黄灯 |
| 不舒适 | PB14 | 红灯 |

接线方式：

```text
PB12 → 电阻 → 绿灯正极，绿灯负极 → GND
PB13 → 电阻 → 黄灯正极，黄灯负极 → GND
PB14 → 电阻 → 红灯正极，红灯负极 → GND
